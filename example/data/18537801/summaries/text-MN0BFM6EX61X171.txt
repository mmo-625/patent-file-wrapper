The invention is an autonomous snow removal machine created by converting a conventional, manually operated gasoline snowblower using a specialized drive conversion assembly, an onboard sensor suite, and an edge computer module. This system allows the machine to operate in both a training mode to map boundaries when no snow is present and an autonomous mode to clear snow while relying primarily on its onboard sensors and stored map. Furthermore, the design supports hybrid operation where a gasoline engine powers the snow auger while electric motors drive the rear wheels, and it can also be adapted for use on industrial, farming, or lawn mowing machines.
