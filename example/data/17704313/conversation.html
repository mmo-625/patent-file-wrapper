Mar 25, 2022
Applicant
I've filed a patent application for Event-Based Machine Learning for a Time-Series Metric.
The invention involves a computerized method and system for generating training samples for an anomaly detection system by analyzing time-series events that impact a target metric. It operates by grouping these events based on shared attributes, determining their influence patterns on the target metric, and clustering the groups with similar influence patterns. Additionally, the process incorporates impact scoring and filtering thresholds to selectively remove irrelevant event groups before or during the clustering phase.
Claim 1 · Original

A computerized method comprising:

receiving a plurality of events that occurred during a time series of a target metric, wherein each event of the events includes an event attribute characterizing the event;

generating a set of event groups for the plurality of events, wherein each event of a respective event group shares a respective event attribute with one or more other events of the respective event group;

for each respective event group of the set of event groups, determining an influence pattern that identifies an influence of the respective event group on the target metric;

clustering the set of event groups into event clusters based on a respective influence pattern of each respective event group, wherein each event cluster includes one or more event groups that share a similar influence pattern; and

generating a plurality of training samples for an anomaly detection system based on a respective event cluster.
