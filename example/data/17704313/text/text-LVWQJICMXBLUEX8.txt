Claim Rejections - 35 USC § 103
The following is a quotation of 35 U.S.C. 103 which forms the basis for all obviousness rejections set forth in this Office action:
A patent for a claimed invention may not be obtained, notwithstanding that the claimed invention is not identically disclosed as set forth in section 102 of this title, if the differences between the claimed invention and the prior art are such that the claimed invention as a whole would have been obvious before the effective filing date of the claimed invention to a person having ordinary skill in the art to which the claimed invention pertains. Patentability shall not be negated by the manner in which the invention was made.
Claim(s) 1-2, 7-8, 11-12, and 17-18 is/are rejected under 35 U.S.C. 103 as being unpatentable over Settle (US 2021/0149754 A1) in view Dodson (US 2018/0316707 A1).
Regarding claims 1 and 11, Settle teaches:
“A computerized method (Settle, ¶ 111-112 teaches a processor and a memory to execute method steps) comprising: receiving a plurality of events that occurred during a time series of a target metric (Settle, ¶ 44 and 74 receiving a series of a events over a time window related to a given metric), wherein each event of the events includes an event attribute characterizing the event (Settle, ¶ 47, the events include attribute information); generating a set of event groups for the plurality of events (Settle, ¶ 47 and 53-54 events are grouped), wherein each event of a respective event group shares a respective event attribute with one or more other events of the respective event group (Settle, ¶ 47 and 53-54 events are grouped based on attribute information); for each respective event group of the set of event groups; clustering the set of event groups into event clusters (Settle, ¶ 58-60, and 77-90 event groups are clustered together); and generating an anomaly detection system based on a respective event cluster (Settle, ¶ 48-49, and 65-68 the system is used to create an anomaly detection system)”.
Settle does not, but in related art, Dodson teaches:
“for each respective event group of the set of event groups, determining an influence pattern that identifies an influence of the respective event group on the target metric (Dodson, ¶ 34, 46, 64-65, and 68 teach determining the influences that effect anomalous behavior in various groups related to metrics of computing resources);
clustering the set of event groups into event clusters based on a respective influence pattern of each respective event group, wherein each event cluster includes one or more event groups that share a similar influence pattern (Dodson, ¶ 68-73 and 84 the groups are clustered in light of the determine influence of various attributes);
and generating a plurality of training samples for an anomaly detection system based on a respective event cluster (Dodson, Figs. 5 and 6, ¶ 81, 91-95, and 98-100 teaches the deducing information from the clusters into feature vectors and using them to create a classier rule for anomaly detection)”.
Before applicant’s earliest effective filing it would have been obvious to one of ordinary skill in the art, having the teachings of Settle and Dodson, to modify the anomaly detection and clustering system of Settle to include the method to use influence of factors to improve an anomaly detection system. The motivation to do so constitutes applying a known technique to known devices and/or methods ready for improvement to yield predictable results.
Regarding claims 2 and 12, Settle in view of Dodson teaches:
“The computerized method of claim 1 (Settle in view of Dodson teaches the limitations of the parent claims as discussed above) wherein each respective training sample represents the respective influence pattern of the respective event cluster and corresponds to an event from the respective event cluster (Dodson, Figs. 5 and 6, ¶ 81, 91-95, and 98-100 teaches the deducing information from the clusters into feature vectors and using them to create a classier rule for anomaly detection)”.
Regarding claims 7 and 17, Settle in view of Dodson teaches:
“The computerized method of claim 1 (Settle in view of Dodson teaches the limitations of the parent claims as discussed above) wherein the event attribute characterizing the respective event is a textual description of the respective event (Dodson, ¶ 11 and 102 the attribute for the event is a text string)”.
Regarding claims 8 and 18, Settle in view of Dodson teaches:
“The computerized method of claim 1 (Settle in view of Dodson teaches the limitations of the parent claims as discussed above) wherein the anomaly detection system is a machine-learning-based anomaly detection system (Dodson, ¶ 28-29 and 53 teaches a machine learning based anomaly detection system)”.
