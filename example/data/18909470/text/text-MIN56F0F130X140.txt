## Reasons for Allowance
The following is an examiner’s statement of reasons for allowance:
Independent claim 1 recites “A system for automating actions on a software user interface, comprising: a processor; and a memory storing instructions which, when executed, cause the processor to perform steps comprising: constructing an artificial intelligence agent based on a Transformer based vision language model configured to automate actions on a software user interface, including training the Transformer based vision language model on: a first training dataset including documents containing text interleaved with images; a second training dataset including text embedded in images; a third training dataset including recorded videos of software usage; a fourth training dataset including portable document format (PDF) documents; a fifth training dataset including recorded videos of software tool usage trajectories; a sixth training dataset including images of open-domain web pages; a seventh training dataset including images of specific-domain web pages; and an eighth training dataset including images of agentic trajectories of the agent performing interface automation task workflows; receiving, via a user interface, a natural language input indicating a user intent to interact with the software user interface; generating, by the Transformer based vision language model, a workflow indicating a past action and a next action relating to the user intent based on an input comprising a screenshot of the software user interface and the natural language input; executing, by the artificial intelligence agent, at least the next action in a form of a machine-actuated command on the software user interface thereby resulting in a change in the software user interface; and iteratively generating, by the Transformer based vision language model, next machine-actuated commands based on a screenshot of a changed software user interface; and iteratively executing, by the artificial intelligence agent, the next machine- actuated commands thereby causing a task described by the natural language input to be completed by interacting with the software user interface. The cited art of record does not render such a combination of features obvious.
The closest prior art of record, Lu, is directed to “a digital agent” that “controls a web browser…to solve real-world tasks”. Lu discloses “a digital agent” that “controls a web browser…to solve real-world tasks”, e.g., scheduling an event in Google Calendar in Fig. 1 or creating a request on a food delivery site in Fig. 4. Lu discloses that a user may enter a natural language prompt such as “Create a task for a Career Fair on Google Calendar”, and that the underlying model will generate a workflow of past and next actions based thereon. For example, Fig. 1 shows that the model iteratively performs actions including “load”, “click”, “input”, and “say” using screenshots of the Google Calendar software which are updated with each action, thereby performing the action command from the user prompt. Lu discloses that the model is trained on browser screenshots including “images and text”, “demonstration-level video recordings”, and example trajectories of the usage of the software tools including “browser screenshots” across “155 real-world websites” from “demonstration-level video recordings”.
Lu does not teach or suggest that the model is a Transformer based model which is trained on: a first training dataset including documents containing text interleaved with images; a fourth training dataset including portable document format (PDF) documents; and a seventh training dataset including images of specific-domain web pages, as required by independent claim 1.
Singh (U.S. Patent Application Publication No. 2023/0360388; cited in the IDS filed 5/16/25), like Lu, is directed to a machine learning model trained on screenshots and video for recognizing user interaction with an application. Singh discloses that the model is a transformer-based one.
Koh (“VisualWebArena: Evaluating Multimodal Agents on Realistic Visual Web Tasks”), like Lu, is directed to an autonomous agent for automating computer tasks. Koh discloses that the underlying model of the agent is trained on text interleaved with images.
He (“WebVoyager: Building an End-to-End Web Agent with Large Multimodal Models”), like Lu, is directed to a trained web agent. He contemplates training the underlying model using PDFs.
Liu (“VisualWebBench: How Far Have Multimodal LLMs Evolved in Web Page Understanding and Grounding”), like Lu, is directed to “web agent tasks” based on “Multimodal Large Language models (MLLMs)”. Liu discloses that the tasks include Heading OCR, Captioning, and WebQA (Fig. 1).
However, one of ordinary skill in the art would not have cobbled together the teachings of the above five references to arrive at the claimed invention without the benefit of improper hindsight. Indeed, applying the teachings of Singh, Koh, He, and Liu to the teachings of Lu would have required the teachings of the Applicants’ disclosure to arrive at a method comprising a Transformer based model which is trained on: a first training dataset including documents containing text interleaved with images; a fourth training dataset including portable document format (PDF) documents; and a seventh training dataset including images of specific-domain web pages, within the context of the remaining features of independent claim 1. Accordingly, claim 1 is allowed. Claims 2-18 are allowed by virtue of their dependency on claim 1.
